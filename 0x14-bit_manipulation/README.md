# 0x14 - Bit Manipulation

This project focuses on bitwise operations in C.

## Learning Objectives
- Understanding bitwise operators (&, |, ^, <<, >>, ~)
- Converting between binary and integers
- Manipulating individual bits
- Checking endianness

## Files
- `main.h` – header with prototypes
- `0-binary_to_uint.c` – convert binary string to unsigned int
- `1-print_binary.c` – print number in binary (no arrays, no malloc, no / or %)
- `2-get_bit.c` – get bit at index
- `3-set_bit.c` – set bit to 1 at index
- `4-clear_bit.c` – set bit to 0 at index
- `5-flip_bits.c` – count bits to flip to convert n to m
- `100-get_endianness.c` – check endianness

## Compilation:
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
