# 0x13 - More Singly Linked Lists

This project extends linked list concepts with integer data.

## Learning Objectives
- Advanced linked list operations
- Insertion and deletion at arbitrary positions
- Reversing linked lists
- Detecting loops in linked lists

## Files
- `lists.h` – header with struct and prototypes
- `0-print_listint.c` – print all elements
- `1-listint_len.c` – count nodes
- `2-add_nodeint.c` – add node at beginning
- `3-add_nodeint_end.c` – add node at end
- `4-free_listint.c` – free list
- `5-free_listint2.c` – free list and set head to NULL
- `6-pop_listint.c` – delete head node
- `7-get_nodeint.c` – get node at index
- `8-sum_listint.c` – sum all data
- `9-insert_nodeint.c` – insert node at index
- `10-delete_nodeint.c` – delete node at index
- `100-reverse_listint.c` – reverse list
- `101-print_listint_safe.c` – print list with loop detection
- `102-free_listint_safe.c` – free list with loop detection
- `103-find_loop.c` – find start of loop

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
