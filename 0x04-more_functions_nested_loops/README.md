# 0x04 - C More functions, more nested loops

This project introduces more C functions and nested loops.

## Learning Objectives
- Nested loops and how to use them
- Functions and prototypes
- Difference between declaration and definition
- Scope of variables
- gcc flags: -Wall -Werror -Wextra -pedantic -std=gnu89
- Header files and #include

## Files
- `0-isupper.c` - checks for uppercase character
- `1-isdigit.c` - checks for a digit
- `2-mul.c` - multiplies two integers
- `3-print_numbers.c` - prints 0 to 9
- `4-print_most_numbers.c` - prints 0 to 9 except 2 and 4
- `5-more_numbers.c` - prints 0 to 14 ten times
- `6-print_line.c` - draws a straight line
- `7-print_diagonal.c` - draws a diagonal line
- `8-print_square.c` - prints a square
- `9-fizz_buzz.c` - FizzBuzz 1 to 100
- `10-print_triangle.c` - prints a triangle
- `100-prime_factor.c` - largest prime factor of 612852475143
- `101-print_number.c` - prints an integer
- `main.h` - header file with all prototypes

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o output
