# 0x02 - C Functions, Nested Loops

This project introduces C functions and nested loops.

## Learning Objectives
- Nested loops
- Function declarations, definitions, and prototypes
- Scope of variables
- Header files and include guards
- gcc flags: -Wall -Werror -Wextra -pedantic -std=gnu89

## Files
- `0-putchar.c` - prints "_putchar"
- `1-alphabet.c` - prints lowercase alphabet
- `2-print_alphabet_x10.c` - prints alphabet 10 times
- `3-islower.c` - checks for lowercase character
- `4-isalpha.c` - checks for alphabetic character
- `5-sign.c` - prints the sign of a number
- `6-abs.c` - computes absolute value
- `7-print_last_digit.c` - prints last digit of a number
- `8-24_hours.c` - prints every minute of the day
- `9-times_table.c` - prints the 9 times table
- `10-add.c` - adds two integers
- `11-print_to_98.c` - prints natural numbers from n to 98
- `100-times_table.c` - prints the n times table
- `101-natural.c` - sum of multiples of 3 or 5 below 1024
- `102-fibonacci.c` - first 50 Fibonacci numbers
- `103-fibonacci.c` - sum of even Fibonacci terms
- `104-fibonacci.c` - first 98 Fibonacci numbers

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o output
