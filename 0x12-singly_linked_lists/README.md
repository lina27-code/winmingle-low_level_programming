# 0x12 - Singly Linked Lists

This project introduces singly linked lists in C.

## Learning Objectives
- When and why to use linked lists vs arrays
- How to build and traverse linked lists
- Memory management with malloc and free

## Files
- `lists.h` – header file with struct definition and function prototypes
- `0-print_list.c` – prints all elements of a list
- `1-list_len.c` – returns the number of nodes
- `2-add_node.c` – adds a node at the beginning
- `3-add_node_end.c` – adds a node at the end
- `4-free_list.c` – frees a linked list
- `100-first.c` – prints a message before main
- `101-hello_winmingle.asm` – assembly program

## Compilation
All files compiled with: gcc -Wall -Werror -Wextra -pedantic -std=gnu89
