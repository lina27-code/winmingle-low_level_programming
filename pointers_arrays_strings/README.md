# Pointers, Arrays, and Strings

This project covers pointers, arrays, and string manipulation in C.

## Learning Objectives
- Pointers and how to use them
- Arrays and how to use them
- Differences between pointers and arrays
- String manipulation
- Scope of variables

## Files
- `0-reset_to_98.c` - reset an integer to 98 via pointer
- `1-swap.c` - swap two integers via pointers
- `2-strlen.c` - return the length of a string
- `3-puts.c` - print a string followed by a new line
- `4-print_rev.c` - print a string in reverse
- `5-rev_string.c` - reverse a string in place
- `6-puts2.c` - print every other character of a string
- `7-puts_half.c` - print the second half of a string
- `8-print_array.c` - print n elements of an integer array
- `9-strcpy.c` - copy a string
- `10-atoi.c` - convert a string to an integer
- `101-keygen.c` - generate random valid passwords
- `main.h` - header file with all prototypes

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o output
